# ShopSphere End-to-End User & Administrator Guide

## 1. Customer Shopping Workflow

```text
Browse Storefront (Home / Categories)
        ↓
Search & Filter by Brand / Price / Rating
        ↓
Open Product Details & Select Quantity
        ↓
Add to Wishlist or Add to Cart / Buy Now
        ↓
Open Cart & Apply Promo Coupon (e.g. WELCOME10)
        ↓
Proceed to Checkout
        ↓
Select / Add Delivery Address
        ↓
Choose Payment Method (Cash on Delivery / Mock Online Payment)
        ↓
Place Order & View Instant Confirmation
        ↓
Track Order Lifecycle Timeline (Placed -> Confirmed -> Packed -> Shipped -> Delivered)
        ↓
Submit Verified 1-5 Star Customer Review
```

---

## 2. Administrator Workflow

```text
Login to Admin Portal (/admin)
        ↓
Review Live Executive Metrics & Charts (Sales, Orders, Low Stock)
        ↓
Manage Product Catalog (Create, Edit, Upload Image, Set Discounts, Update Stock)
        ↓
Manage Categories (Create, Edit, Toggle Activation)
        ↓
Fulfill Customer Orders (Update Order Status & Payment Status)
        ↓
Supervise Customer Accounts (Toggle Account Status)
        ↓
Configure Discount Coupons (Percentage / Fixed Value Promo Codes)
        ↓
Inspect Security Audit Trails
```
